Analog Meters

Professional analog panel meters for precise measurement of current, voltage, and frequency. Available in 72x72mm and 96x96mm sizes with Class 1.5 accuracy.

AK-A72-XXD – Analog Ammeter Direct Connection 72x72mm

Compact 72x72mm analog ammeter with direct connection for current measurement from 5A to 100A. Features Class 1.5 accuracy and clear analog scale display for reliable operation in electrical panels.

AK-A96-XXD – Analog Ammeter Direct Connection 96x96mm

Standard 96x96mm analog ammeter with direct connection for current measurement from 5A to 100A. Features large easy-to-read analog scale and Class 1.5 accuracy for distribution panels.

AK-A72-XXX – Analog Ammeter with CT 72x72mm

Compact 72x72mm analog ammeter designed for use with external current transformers. Supports CT ratios from 5/5A to 6300/5A for high current measurement applications with Class 1.5 accuracy.

AK-A96-XXX – Analog Ammeter with CT 96x96mm

Standard 96x96mm analog ammeter for use with external current transformers. Supports CT ratios from 5/5A to 6300/5A with large easy-to-read scale and Class 1.5 accuracy.

AK-V72-500V – Analog Voltmeter 500V AC 72x72mm

Compact 72x72mm analog voltmeter designed for 500V AC voltage measurement. Features Class 1.5 accuracy, clear analog scale, and high input impedance for minimal circuit loading.

AK-V96-500V – Analog Voltmeter 500V AC 96x96mm

Standard 96x96mm analog voltmeter for 500V AC measurement. Features large easy-to-read scale, Class 1.5 accuracy, and high input impedance for reliable voltage monitoring.

AK-V72-XX/0.1 – Analog Voltmeter with PT 72x72mm

Compact 72x72mm analog voltmeter with potential transformer (PT) unit for high voltage measurement. Supports customizable PT ratios (XX/0.1) with Class 1.5 accuracy and safe isolation.

AK-V96-XX0,1 – Analog Voltmeter with PT 96x96mm

Standard 96x96mm analog voltmeter with PT unit for high voltage measurement. Supports customizable PT ratios with large easy-to-read scale and Class 1.5 accuracy.

AK-F72 – Analog Frequency Meter 72x72mm

Compact 72x72mm analog frequency meter for accurate frequency measurement (45-65 Hz). Features Class 1.5 accuracy, clear analog scale, and fast response time for real-time monitoring.

AK-F96 – Analog Frequency Meter 96x96mm

Standard 96x96mm analog frequency meter for accurate frequency measurement (45-65 Hz). Features large easy-to-read scale, Class 1.5 accuracy, and fast response time.
